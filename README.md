## Featured training exercise

**[Case 001 — Operation False Ticket](investigations/001-fraud-pattern-analysis/)** is a **fictional** beginner crime-pattern exercise. It presents three suspected ticket-fraud incidents and asks whether there is enough evidence to link them. The assessment is intentionally **not yet completed**; the next step is to evaluate the reports and document a reasoned conclusion.

## Project principles

1. **Evidence before conclusions.** Separate source facts, interpretations, assumptions, and gaps.
2. **Traceable sourcing.** Link primary sources, record retrieval dates, and acknowledge limitations.
3. **Calibration.** Explain confidence and alternative hypotheses instead of overstating certainty.
4. **Ethics first.** Use lawfully accessible information. Do not publish private personal information, target private individuals, or bypass access controls.
5. **Honest attribution.** Clearly distinguish fictional exercises, pending work, and completed original analyses.

> This is an independent learning project, not an official FBI or government investigation. Repository entries are not professional intelligence determinations.
