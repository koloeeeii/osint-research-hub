# OSINT Tools & Public Sources

This is a **curated learning directory**, not an endorsement of every tool or a claim of proficiency. Each resource will be documented as it is tested. Start with the investigation question, then choose the appropriate tool.

| Tool / source | Purpose | Beginner exercise | Caution |
| --- | --- | --- | --- |
| [Google Advanced Search](https://www.google.com/advanced_search) | Locate targeted public documents and pages | Find an official agency report by topic and file type | Search results are not proof of a claim |
| [Wayback Machine](https://web.archive.org/) | Inspect archived public web pages | Compare two versions of an agency site | Archives may be incomplete |
| [Google Lens](https://lens.google/) | Search for similar images and possible origins | Find an earlier publication of a public image | Similarity is not provenance |
| [Google Earth](https://earth.google.com/) | View locations and geographic context | Compare landmarks in a public photo | Imagery dates and coverage vary |
| [USAspending](https://www.usaspending.gov/) | Explore US federal award and spending data | Find contracts awarded by an agency | Awards, obligations, and payments differ |
| [PACER](https://pacer.uscourts.gov/) | Access federal court dockets and documents | Identify public filings in a closed case | Fees, privacy limits, and records availability apply |
| [FBI News](https://www.fbi.gov/news) | Find official releases and public case summaries | Build a case-event timeline | Agency releases are a source, not independent corroboration |
| [DOJ News](https://www.justice.gov/news) | Find official prosecution and sentencing releases | Distinguish indictment from conviction | An allegation is not an adjudicated fact |

## How each tool entry will grow

For each tool I actually use, I will add: **what it does, when to use it, required inputs, accessibility/cost, documented limitations, an example task, and a date last reviewed**.

## Responsible use

Use publicly and lawfully accessible information. Do not attempt unauthorized access, scrape restricted data, investigate private individuals without a defensible purpose, or expose personal contact details.
