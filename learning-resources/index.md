# OSINT Learning Resources

Start with fundamentals, then practice on controlled exercises before undertaking open-ended real-world investigations.

## Four-week practice plan

| Week | Focus | Deliverable |
| --- | --- | --- |
| 1 | Search, source credibility, documentation | An annotated five-source research brief |
| 2 | Image verification and historical research | Two documented verification exercises |
| 3 | Crime-pattern analysis | Case 001 evidence matrix and preliminary assessment |
| 4 | Public-record case reconstruction | A documented timeline with cited primary sources |
